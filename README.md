# 一人內容部（語剪室）

給線上教練、顧問、知識型創作者的 **Claude Code 外掛**：從找定位、排內容日曆，到錄影、剪輯、雙語字幕、輪播圖與圖卡，一路協助你把第一批內容發出去。

> **狀態：內測版 0.1.0。** 目前只用合成資料在 Windows 驗證過，**還沒有真人使用者試用**，Mac 完全沒測，外掛的實際安裝流程也尚未驗證。請當成實驗中的工具，**不保證任何流量、觀看、名單或收入的成果。**

## 需要什麼

| 項目 | 說明 |
|---|---|
| Claude Code | 你自己的訂閱與安裝 |
| Git | 從 GitHub 安裝外掛時需要（**不需要 GitHub 帳號**） |
| Python 3.9 以上 | 執行腳本 |
| ffmpeg | 剪輯與字幕 |

第一次使用會自動檢查環境，缺什麼會告訴你，**取得你同意後**才安裝缺少的 Python 套件；系統層級的軟體（如 ffmpeg）請你自己安裝。

## 安裝

在 Claude Code 對話中輸入：

```text
/plugin marketplace add daxingcourse/zh-video-marketplace
/plugin install zh-video-kit@zh-video-marketplace
```

接著對 Claude 說：

```text
幫我開始
```

## 裡面有什麼

| 技能 | 做什麼 |
|---|---|
| 語剪室 | 剪停頓、贅詞、口吃、重錄，加上中英雙語字幕（中文轉錄輸出繁體） |
| 內容日曆 | 訪談、定位卡、素材卡、30 天日曆、完整稿、錄影重點卡與批次切片 |
| 輪播圖 | 純文字排版的輪播圖，三種配色 |
| 動態圖卡 | 在影片上疊加標題、重點、數字、引言與下三分之一字卡 |
| 新手導師 | 七天路徑：第七天把第一批內容發出去；環境檢查、常見問題 |
| 導流文件 | ManyChat 與 LINE 官方帳號的流程設計與模板（文件，尚未實際操作驗證） |

## 設計原則

- **不編造你的背景**：經歷、證照、案例與成果只採用你說過的話。
- **你做最後決定**：剪點、校對、翻譯、預覽、發布前都會停下來等你確認。
- **Claude 聽不到聲音、看不到畫面**：剪接點順不順、圖卡有沒有擋到臉，要你自己看與聽。
- **用語提示不是法律判斷**：命中風險用語時只提醒，請專業人士確認。

## 關於隱私，請看清楚

- 你的**影片檔與逐字稿檔案**由本機腳本處理，存在你自己的電腦，**不會上傳到我們的伺服器**（我們沒有伺服器）。
- **但 Claude 為了幫你校對、翻譯、寫稿，會讀取逐字稿的文字內容**，這些文字依 Claude Code 的運作方式會傳送給 Anthropic。這部分請參考 Anthropic 的隱私說明，並**不要處理含有他人個資、機密或你不願傳送的內容**。
