# 更新紀錄

## [0.1.0] 內測版（尚未發布）

這是第一個版本，目前**只用合成資料驗證過，尚未有真人使用者試用**，也只在 Windows 上實測。

### 新增
- **語剪室**（剪輯與雙語字幕）：剪停頓、贅詞、口吃、重錄；中文轉錄（繁體）；中英雙語字幕燒錄；剪點貼齊真實靜音，不確定的列為待審核。
- **內容日曆**：訪談、定位卡、30 天日曆；素材採集與素材卡；完整稿與來源檢查；日曆檢查與用語提示；匯出 CSV。
- **錄影**：每支影片的重點卡、批次錄製（每支先唸「第 N 支」）、自動切片。
- **圖文工坊**：輪播圖產生器，三種配色。
- **動態圖卡**：在口播影片上疊加標題卡、重點卡、數字卡、引言卡、下三分之一字卡，淡入與滑入動畫，位置避開字幕。自製（ffmpeg 與 Pillow），不使用第三方圖片。
- **導流**：ManyChat 與 LINE 官方帳號的流程設計與模板（文件，尚未實際操作驗證）。
- **新手導師**：七天路徑（第七天把第一批內容發出去）、練習影片、環境檢查、常見問題、求助報告。
- 內附開源字型 Noto Sans TC（SIL OFL 1.1）。

### 已知問題與限制
- 沒有真人口播與真人錄影的驗證。
- **Mac 沒有任何實測**。
- 外掛的真實安裝流程（`/plugin marketplace add`、`/plugin install`）尚未驗證。
- 語音辨識會自動修飾口語，口吃與部分贅詞在逐字稿裡看不到就剪不到。
- 剪接點的聽感必須由使用者自己聽。
- 輪播圖版型有限，沒有照片與插圖。
- **圖卡有沒有擋到講者的臉，沒有驗證**（測試影片沒有人臉，也沒有做人臉偵測），要靠預覽人工確認。
- B-roll、排程發布尚未提供。
