# 輪播圖產生器

輸入日曆中的一天，輸出 5 到 8 頁輪播圖。**文字排版，不生圖。** 好處是沒有肖像、素材授權問題，也不會出現 AI 圖常見的錯字與怪手。

## 你的角色與界線

- 內容必須來自使用者說過的話與日曆項目，**不編造數據、案例、見證、證照**。不確定的就留【待補】，不要用空泛的話填。
- 不保證成效。受規範領域（醫療、營養、保健、財務、投資、法律、心理）要在 `footer_note` 放一句提醒，例如「一般性資訊，不是個人建議」，並把工具列出的用語提示逐項告訴使用者。**用語提示不是法律判斷。**
- 設計給使用者最後決定。你推薦，他選主題與文字。
- 你看得到排版結果，但**使用者要自己打開每一頁看過再發布**。

## 流程

### 1. 從日曆建立草稿

```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/carousel-maker/scripts/carousel_render.py" init calendar.json 2026-10-09 -o slides.json
```

草稿包含封面（主題與鉤子）、幾頁內文（依日曆的 `script` 拆出）、最後一頁行動呼籲。內文欄位是【待補】。

### 2. 和使用者一起把內容填完

**每頁一個重點**，一頁不要塞太多：

| 頁 | 建議 |
|---|---|
| 封面 | 標題 20 字內，講清楚「這篇會得到什麼」或提出一個問題；副標補一句 |
| 內文 | 標題一句話＋內文 2 到 4 句；或用條列頁（`list`）放 3 到 5 點，每點一行 |
| 最後一頁 | 一個行動：收藏、留言關鍵字、提問。名單類要放 `keyword` 與註明自動回覆的 `note` |

- 總頁數 5 到 8 頁常見，**建議** 10 頁內（這是建議，不是平台上限）。
- 中文沒有自動斷詞，標題偶爾會把詞拆在兩行。可在文字裡用 `\n` 手動換行，例如 `"先分清楚：\n時間，還是總量？"`。
- 內文寫使用者的口吻。先問他：「這句話你會這樣說嗎？」
- `meta.footer_note`：受規範領域必填；`meta.handle`：使用者的帳號；`meta.eyebrow`：內容支柱（顯示在封面）。

### 3. 排版

```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/carousel-maker/scripts/carousel_render.py" render slides.json -o out/ --theme paper
```

- 主題：`paper`（淺灰藍、青綠重點）、`ink`（深藍、字幕黃重點）、`sage`（灰綠）。讓使用者選。
- 預設 1080x1350（4:5 直式）。其他尺寸用 `--size`。
- 還有【待補】會**拒絕輸出**。只想先看版型可加 `--allow-todo`，但這只供預覽，**不能發布**。
- 預設使用隨套件附的開源字型 Noto Sans TC（SIL OFL）。要換字型用 `--font` 指定檔案（`--bold` 指定粗體），**字型授權由你自行確認**；可變字型可寫成 `路徑|Bold`。

### 4. 處理警告

| 警告 | 處理 |
|---|---|
| 文字太長，放不下 | 縮短該頁文字，或拆成兩頁 |
| 用語提示 | 逐項告訴使用者；他或專業人士確認後決定要不要改。你不要自行宣告「沒問題」 |
| 頁數過多 | 拆成系列貼文，或合併重點 |

### 5. 配文

輪播圖本身不含貼文配文。請使用者一起寫：

- 第一句要和封面一樣吸引人。
- 若有導流關鍵字，說清楚留言後會發生什麼（收到自動回覆的連結），並與 `${CLAUDE_PLUGIN_ROOT}/skills/content-calendar/references/manychat.md` 的做法一致。
- 同樣要避免保證性用語。

### 6. 更新狀態

```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/content-calendar/scripts/recording_tools.py" status calendar.json 2026-10-09 已剪
```

（圖文沒有「錄」，做完圖可標「已剪」，發布排程後標「已排程」。）

## 已知限制

- 純文字排版，版型有限（封面、內文、條列、行動呼籲四種）。想要照片、插圖或品牌視覺，需要使用者自備素材另行處理，目前未支援。
- 版型是通用設計，不代表使用者的品牌識別。
- 沒有自動斷詞；不處理直排與多語混排的細緻字距。
- 內附字型是固定字重的 Regular 與 Bold，沒有其他字重。

## 測試狀態

- 已驗證：三個主題的 5 頁範例排版（目視檢查）、字級自動縮放、行首行尾禁則、【待補】阻擋、用語提示、溢出警告、未知版型報錯、從日曆建立草稿、從打包結果執行。
- **未驗證**：真實內容在不同長度下的版面表現（極短、極長）；在 Mac 或其他字型上的外觀；使用者實際的接受度。
