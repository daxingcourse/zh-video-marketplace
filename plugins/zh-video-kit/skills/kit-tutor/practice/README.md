# 練習影片

用來走完第一次完整流程。影片由你電腦的內建語音即時產生，不含任何第三方錄音，所以可以放心練習。

## 產生
```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/kit-tutor/practice/make_practice.py"   # 會在你目前所在的資料夾產生 practice.mp4
```
- Windows：需要「Microsoft Hanhan」台灣中文語音（多數 Windows 10/11 內建）。
- macOS：使用 `say -v Meijia`（**此路徑尚未實測**）。
- 產生失敗或系統不支援：改用自己手機錄一段，照 `${CLAUDE_PLUGIN_ROOT}/skills/kit-tutor/record-test-script.md` 做。

會在你**目前所在的資料夾**得到 `practice.mp4`（直式，約 40 秒）與 `script.txt`（原稿）。

## 這支影片裡埋了什麼
| 位置（約） | 內容 | 練習重點 |
|---|---|---|
| 開頭 | 沉默約 2 秒 | 剪開頭與長停頓 |
| 5 秒 | 「嗯」 | 單獨成詞的語助詞，自動剪 |
| 6 秒 | 「我想我想」 | **連續語流中的口吃**，邊界不準，需要你聽過再決定 |
| 11 秒 | 「呃」（常被聽成「二」） | 同音字誤辨，要看前後文判斷 |
| 17 秒 | 「那個」、「口誤」被聽成「口物」 | soft 贅詞要不要剪；校對階段改同音字 |
| 22～29 秒 | 「第三個技巧…不對，重來」再講一次 | **重錄**：保留最後一次 |
| 33 秒後 | 長停頓與結尾靜音 | 剪結尾 |

## 操作
```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/zh-video-pipeline/scripts/pipeline.py" prepare my_practice --video practice.mp4 --hotwords "Claude Code"
```
之後依畫面指示審核、翻譯、`cut`、`finish`。

## 參考解答（你的結果會略有不同）
這是在開發機器上實測的結果。語音辨識每台電腦、每個版本都可能不同，**不要求一模一樣**。

**自動剪（不用你決定）**：開頭靜音、各處長停頓、「嗯」。

**待審核，建議做法**
| 項目 | 建議 | 理由 |
|---|---|---|
| 「二」（11 秒） | 剪 | 前後都是停頓，獨立一個字，是「呃」被聽錯 |
| 「就是」、「那個」、「對」 | 先不剪 | 「就是」在這裡是正文；「不對」的「對」是詞的一部分 |
| 「我我」（22 秒） | 不用管 | 這段整個是重錄，會被一起剪掉 |
| 「我想我想」（6 秒） | 聽過再決定 | 工具標示「邊界在連續語流，可能吃字」。用 `ffplay -ss 5.5 -t 2.5 practice.mp4` 聽一次 |

**重錄（要自己補）**：讀 `sentences.txt`，第 5、6 句（「第三個技巧，我我會用…不對，重來」）是失敗的那一次，保留第 7 句。把這一整段的時間範圍加進 `cut_plan.json` 的 `cuts`，格式見 `${CLAUDE_PLUGIN_ROOT}/skills/zh-clean-cut/SKILL.md`。

**校對**：「口物」改成「口誤」。

**預期結果**：約 40 秒剪成約 21 秒。剪後影片重新轉錄，「嗯」「呃」與重錄那段都應該消失，沒有被吃掉的字。「我想我想」若你決定不剪，會保留。
