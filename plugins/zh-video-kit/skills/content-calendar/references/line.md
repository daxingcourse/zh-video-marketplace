# 導流設計：LINE 官方帳號

> **來源與日期**：方案與費用取自 [LINE Biz-Solutions 官方公告](https://tw.linebiz.com/column/LINEOA-2026-Price-Plan/)（頁面日期 2026/09/01）。**價格會調整，教學前請再看一次官方頁面。**
> **我沒有驗證的部分**：LINE 關鍵字自動回應的細部規則（比對方式、可設定數量、是否可帶連結與圖片等），這些來自第三方文章或我沒查，請以官方說明為準。
> 你的角色：設計流程、給模板、教學。**不要代替使用者登入或操作他的帳號。**

## 為什麼要有這份

ManyChat 官方通路清單查不到 LINE（第三方資料，官方頁面擋住機器存取，待你自己確認）。但台灣的名單常在 LINE，所以要有 LINE 版本的做法，不要硬套 ManyChat。

## 方案與費用（2026，官方）

| 方案 | 月費 | 免費訊息則數 | 加購 |
|---|---|---|---|
| 輕用量 | 0 元 | 200 則 | 不可 |
| 中用量 | **800 元，2026/11/1 起調為 1,000 元** | 3,000 則 | 不可，需升級高用量 |
| 高用量 | **1,200 元，2026/11/1 起調為 1,400 元** | 6,000 則 | 可，階梯式累進計價 |

加購（高用量）：第 1 到 50,000 則 0.2 元／則；第 50,001 則起 0.15 元／則。

## 哪些訊息算則數

| 計入則數 | **不計**則數 |
|---|---|
| 推播群發訊息 | 加入好友的歡迎訊息、一對一聊天訊息、自動回應訊息、AI 自動回應訊息、Messaging API 的 Reply API |

**對「關鍵字導流」的意義**：觀眾傳關鍵字、系統自動回應，這一段屬於「自動回應」，依官方公告**不計入則數**。要花則數的是**之後的群發推播**。所以起步用輕用量就可能夠用，費用壓力在日後的推播。

## 與 ManyChat 的差別（設計層面）

| 面向 | ManyChat（Instagram 等） | LINE 官方帳號 |
|---|---|---|
| 觸發方式 | 在貼文**留言**關鍵字，系統私訊 | 觀眾要先**加入好友**，再傳關鍵字 |
| 摩擦 | 留言一步 | 加好友加傳訊兩步 |
| 名單歸屬 | 在 Meta 平台與 ManyChat 帳號中 | 在 LINE 官方帳號中 |
| 後續推播 | 受平台訊息窗口限制 | 可群發，但**計入則數與費用** |
| 適合 | 從 Instagram 或 Facebook 引流 | 客群已習慣用 LINE，或要長期經營名單 |

## 流程設計

```
貼文／影片引導（留言區或簡介放 LINE 連結）→ 加入好友 → 歡迎訊息（含揭露）→ 傳關鍵字 → 自動回應資源
```

- Instagram 不一定能在留言裡直接放連結，**通常是請觀眾去簡介點連結**。這個細節各平台常變，教學時請使用者自己確認當下的規則。
- 日曆的 `cta_keyword` 在 LINE 流程裡同樣有用，但文案要寫成「加好友後傳『外食』」。

## 訊息模板

**歡迎訊息（自動，含揭露）**

```
嗨，歡迎加入【名稱】🙌
這是自動回覆。想拿【資源名稱】，請直接傳「【關鍵字】」給我。
想問問題也可以直接打字，我看到會回覆你。
```

**關鍵字回應**

```
這是你要的【資源名稱】：【連結】
想先問你一個小問題：你比較常遇到【情境 A】還是【情境 B】？
（回覆 A 或 B 就好）
```

## 注意事項

- 揭露自動回覆；給資源；提供讓人自然離開的方式（封鎖或退訂的提示）。
- **群發推播要取得明確同意**，並考慮則數與費用。【請律師確認：個人資料保護法的告知，以及行銷訊息的規範】
- 名單是使用者自己的責任，不要放進本套件或傳給第三方。
- 受規範領域（醫療、營養、保健、財務等）的自動回應內容，同樣要避免保證性與療效用語。
