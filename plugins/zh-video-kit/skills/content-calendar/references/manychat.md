# 導流設計：留言關鍵字 → 自動回覆 → 名單

> **資料限制**：以下平台規則與通路支援來自第三方文章，**定案前請對照 Meta 與 ManyChat 的官方文件**。平台規則會變，教學要附查證日期。
> 你的角色是設計流程與教學。**不要代替使用者登入、設定或操作他的帳號**，也不要代他輸入密碼或授權。

## 基本流程

```
貼文／Reel 引導 → 觀眾留言關鍵字 → 自動私訊（含揭露）→ 給資源連結／問一個問題 → 進名單
```

## 已知限制（第三方資料，待官方確認）

| 事項 | 資訊 | 設計上要怎麼做 |
|---|---|---|
| 通路 | ManyChat 支援 Facebook Messenger、Instagram、WhatsApp、Telegram、Email、SMS，另有 TikTok；**查不到原生支援 LINE**（有第三方整合平台宣稱可串接，我沒有驗證，也不建議初學者採用）。ManyChat 官方頁面擋住機器存取，以上來自第三方文章，請自己對照官方 | 若使用者的名單主要在 LINE，改用 `line.md` 的做法，不要硬套 ManyChat |
| 觸發條件 | Instagram 需要使用者先互動（例如留言觸發）才可自動發訊 | 流程一定從「觀眾主動留言」開始，不要設計成主動群發 |
| 24 小時窗口 | 互動後 24 小時內可自動回覆；窗口外不能發推廣訊息 | 所有需要的資訊在第一次回覆就給齊；不承諾「明天再提醒」 |
| 揭露 | 自動訊息需讓對方知道這是自動回覆 | 每個模板的第一句就要有揭露 |
| 傳聞 | 「每小時 200 則」常被當成官方上限，但有文章指出官方文件查無此項 | 教學不要把它當成官方規則 |

## 關鍵字設計

- 6 字內、不含空白、不需要切換輸入法就能打（例如「外食」「菜單」「清單」）。
- 一個關鍵字對應一個資源，不同貼文可以共用同一個。
- 避免容易打錯或與日常留言撞到的字。
- 寫進日曆的 `cta_keyword` 欄位，並讓檢查工具確認是否缺漏。

## 訊息模板（填空）

**第一則（自動回覆，含揭露）**

```
嗨，這是【名稱】的自動回覆 🤖
你留言的是「【關鍵字】」，這是你要的【資源名稱】：【連結】
想先問你一個小問題：你比較常遇到【情境 A】還是【情境 B】？
（回覆 A 或 B 就好。想結束自動回覆，回覆「停止」。）
```

**必備元素**：揭露自己是自動回覆、給資源、一個低門檻的問題、退出方式。

## 蒐集名單的注意事項

- 告訴對方要蒐集什麼資料、做什麼用，並讓他能選擇不給。【請向專業人士（律師）確認：個人資料保護法的告知要求】
- 名單是使用者自己的責任，**不要把名單放進本套件或傳給任何第三方**。
- 不要假設對方同意之後的行銷訊息；取得明確同意再發。

## 你要提供給使用者的東西

1. 一張「流程圖」：貼文 → 留言 → 回覆 → 名單。
2. 兩到三個填好的模板。
3. 設定前的檢查清單：已揭露？有退出方式？第一次回覆就給齊？關鍵字會不會撞？
4. 一份「官方文件對照」清單，讓使用者自己確認最新規則。
