# 定位卡

一頁。每一格都要由使用者確認過，**沒說過的留【待補】**。

## 格式

```markdown
# 定位卡｜【名稱】（日期）

## 一句話定位
我幫【誰】在【什麼情境】解決【什麼問題】，用【什麼方式】。

## 為什麼是我（只寫他說過、可對外說的）
- …
- …

## 受眾
- 是誰：
- 一天的生活／場景：
- 常卡在：
- 常見誤會：（對應「迷思破解」支柱）
- 主要平台：

## 語氣
- 感覺：（親切／專業／幽默／直接）
- 像我的例子：（他自己說的一句話）
- 不講的事與用語：

## 內容支柱（3 到 5 個）
| 支柱 | 它回答什麼 | 為什麼受眾需要 |
|---|---|---|
| | | |

## 導向
- 想讓看完的人做什麼：
- CTA 關鍵字（候選）：
- 要送的東西（例如清單、表單）：【待補／由他準備】

## 製作偏好
- 出鏡：（自己出鏡／不露臉／混合）
- 可投入時間：（每週幾小時）
- 製作路徑傾向：（自己錄／AI聲音／AI數字人／圖文）

## 需要專業人士確認的地方
- （受規範領域的用語、宣稱）
```

## 好與壞的對照

| 壞（空泛） | 好（具體） |
|---|---|
| 我幫助大家變健康 | 我幫常吃外食的上班族，在不改變工作節奏下，看懂外食怎麼選 |
| 我很專業，經驗豐富 | 【他說過的年資與證照】 |
| 語氣：專業又親切 | 語氣：像在跟朋友解釋；例：「這個其實沒有你想得那麼可怕」 |
| 支柱：知識、分享、日常 | 支柱：外食怎麼選、迷思破解、生活小習慣 |

## 檢查

- 把「一句話定位」念給使用者聽，問他：**這是你嗎？** 不是就改，直到他說是。
- 任何看起來像「承諾成效」的字眼都拿掉。
- 受眾描述不要出現真實個人的資料。
