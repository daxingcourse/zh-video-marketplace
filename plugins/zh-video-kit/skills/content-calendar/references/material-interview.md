# 素材採集：把專業變成可用的內容原料

> **用途**：定位訪談回答的是「你是誰、對誰說」。這份回答另一件事：**你有哪些真的可以講的內容**。素材取自使用者本人說過的話，整理成一張張「素材卡」，再排進日曆。
> **設計來源**：2026-10-08 自行設計，出發點是我們日曆的內容支柱與「每項內容必須可追溯到使用者說過的話」的原則。題目依**內容類型**組織，不採固定題數與固定時間。詳見 `原創性守則.md`。

## 原則

- **素材只取自使用者說過的話。** Claude 不補充他沒講的主張、數字、案例或證照。
- 一次一題。每題先說為什麼問，答完用一句話複述。
- 可以用**語音回答**（錄音後轉錄）或**打字**，由使用者選。
- 長度由使用者決定，講到他覺得講完為止。**沒有固定時間分配**；一般建議每題幾分鐘，這只是建議，沒有驗證過。
- 可以跳過任何一題。**不夠就是不夠**：素材少，就老實說日曆能排幾天。
- 客人的故事一律**匿名**：不放真實姓名，也不放可辨識的細節。

## 題目（依內容類型）

使用者的內容支柱不同，重點題也不同。可以依支柱挑 5 到 8 題，不必全部都問。

| # | 提示（照這個意思問，可以改成使用者聽得懂的說法） | 產出的素材類型 | 為什麼問 |
|---|---|---|---|
| 1 | 最近有人問過你什麼問題，讓你覺得「這很多人都想知道」？你當時怎麼回答？ | 常見疑問 | 現成的問與答，最貼近真實需求 |
| 2 | 在你的領域，有哪一句常見的說法，你每次聽到都忍不住想補充？ | 迷思澄清 | 有明確立場的內容容易被記住 |
| 3 | 假設你只有三分鐘，要教一個完全沒基礎的人做一件事，你會教什麼、怎麼教？ | 做法 | 可直接做成教學類內容 |
| 4 | 有沒有一次你做錯了，事後才懂？當時發生什麼，現在你會怎麼做？ | 經驗故事 | 經驗比論述更有說服力 |
| 5 | 有沒有哪件事，你過去的看法和現在不一樣？是什麼讓你改變？ | 觀點轉變 | 呈現專業的成長與思考 |
| 6 | 你幫客人檢查或準備時，習慣固定看哪幾件事？ | 清單 | 容易做成輪播與收藏型內容 |
| 7 | 請描述一個典型的客人情境（不要提姓名或可辨識的細節）：他一開始是什麼狀況？ | 情境（匿名） | 讓受眾認出「這是我」 |
| 8 | 還有什麼你一直想講、卻沒有被問到的？ | 其他 | 開放題，常有意外素材 |

**受規範領域**（營養、保健、醫療、財務、投資、法律、心理）的追加提醒：
- 回答中若出現**療效、保證、具體數字**（例如「幾週瘦幾公斤」「一定有效」），整理成素材卡時**標記為待確認**，請使用者自己確認出處與用語，或請專業人士確認。
- 個案內容要確認**已匿名且已取得同意**。

## 整理成素材卡

流程：

1. 語音回答 → 轉錄 → `outline_transcript.py` 切段（見 SKILL.md），或使用者直接打字。
2. Claude **提議**哪些段落可成為一張卡，使用者確認。
3. 用 `material_tools.py add` 建卡。

### 一張卡的格式

| 欄位 | 說明 |
|---|---|
| `id` | 自動產生（M01、M02…） |
| `type` | `常見疑問`、`迷思澄清`、`做法`、`經驗故事`、`觀點轉變`、`清單`、`情境`、`其他` |
| `line` | **一句話**說這張卡的觀點或內容（建議 40 字內）。**一張卡一個重點** |
| `quote` | 使用者**原話**的片段（選填，但建議填，方便日後忠於原意） |
| `blocks` | 來自錄音的哪幾段（如 `B03`），打字回答則留空 |
| `pillar` | 對應的內容支柱（選填） |
| `check` | 需要使用者確認的事（例如具體數字、療效用語） |
| `used_on` | 用在日曆的哪幾天（自動更新） |

### 好卡與壞卡

| 壞 | 好 |
|---|---|
| 「飲食很重要」（空泛，沒有主張） | 「很多人以為晚上吃澱粉就會變胖，我會先看一整天的總量」（有立場，是使用者說過的話） |
| 一張卡塞三個觀點 | 一張卡一個觀點，其他拆成別張 |
| Claude 加上「研究顯示 70%…」 | 沒有出處就不放；使用者講過的數字，標記待確認 |
| 把客人的真實案例直接寫進去 | 匿名並確認同意 |

## 之後怎麼用

- 日曆項目的 `source` 欄位可以填卡片 id，例如 `["M03"]`；檢查工具可確認 id 存在。
- `material_tools.py stats` 會告訴你：各類型有幾張、哪些還沒用、**素材夠排幾天**。
- 同一張卡可以用在不同格式（例如先做 Reel、再做輪播），**但換格式要換角度，不要原句重複發**。

## 還沒做的

- 從素材卡自動產生完整稿（目前只由 Claude 與使用者在對話中一起寫，並標註取自哪張卡）。
- 素材卡與其他格式（Threads、Email、長文）的對應，尚未加入日曆格式。
